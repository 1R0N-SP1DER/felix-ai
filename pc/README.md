# Faze on the desktop

Install (KDE Neon or any Linux with Python 3.11+):

    git clone https://github.com/1R0N-SP1DER/felix-ai.git
    cd felix-ai/pc
    bash install.sh
    faze

Then open Settings in the window and paste your API keys. Pair your phone from Devices.

Remove with `bash install.sh --remove`. How the phone and PC talk: docs/link.md.
